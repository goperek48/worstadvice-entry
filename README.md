Entry for make.fun's **Worst AI Advice: The 48-Hour Tight Line Open** bounty
(`u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580`).

`main.py` writes one original worst-AI-advice one-liner to `/output/entry.txt`:

> To charge your phone faster, put it in the microwave for 30 seconds — the waves top up the battery in no time.

110 characters — a confident, tidy AI-assistant tip that is concrete (a real
action on a real object), followable (anyone can do it in half a minute), and
regrettable (the phone does not survive). The joke lands in one line, with no
second line to explain it.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (validated: 1–140 characters, UTF-8, not
whitespace-only).
